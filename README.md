# The Bhagavad Gita

A digital presentation of the sacred Hindu scripture, the Bhagavad Gita, featuring all 18 chapters with beautiful styling and responsive design.

## About

The Bhagavad Gita is a 700-verse Hindu scripture that is part of the epic Mahabharata. It is a conversation between Prince Arjuna and the god Krishna, who serves as his charioteer. This digital version presents the timeless wisdom in an accessible web format.

## Features

- Complete 18 chapters of the Bhagavad Gita
- Responsive web design
- Beautiful typography and styling
- Easy navigation between chapters
- Sanskrit titles and spiritual aesthetics

## Live Demo

Visit the live site: [The Bhagavad Gita](https://anshulmehra001.github.io/The-Bhagavad-Gita/)

## Local Development

1. Clone the repository:
```bash
git clone https://github.com/Anshulmehra001/The-Bhagavad-Gita.git
```

2. Open `index.html` in your browser or serve with a local server.

## Deployment

This site is automatically deployed to GitHub Pages using GitHub Actions whenever changes are pushed to the main branch.

## Structure

- `index.html` - Main landing page with chapter navigation
- `chapter-*.html` - Individual chapter pages
- `style.css` - Styling for the entire site
- `text` - Text content file
